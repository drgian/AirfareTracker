One-time setup needed to add or remove trips.
This page saves the watchlist straight into the GitHub repo that powers the dashboard, so the tracker picks it up on its next run. It needs a GitHub token to write:
  1. Open github.com → Settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → drgian/AirfareTracker
  3. Permissions → Repository → Contents: Read and write
  4. Generate, copy the token, paste it below and click Save. It stays in this browser only.
